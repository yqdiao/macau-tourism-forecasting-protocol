# RQ1: Forecast accuracy and computing costs

This directory contains builders and derived results for forecasting accuracy, resource use, break-even pricing, and asymmetric loss.

## Entry points

- `build_rq1.py`: main RQ1 table builder.
- `run_five_quantiles.py` and `build_rq1_five_tau.py`: quantile forecasts and loss comparisons.
- `build_rq1_remaining.py`: additional RQ1 comparisons.
- `figures/`: RQ1 figure outputs.

See the [repository guide](../README.md) for dependencies and upstream prediction requirements. These scripts do not by themselves reproduce every upstream forecast.
