# 澳门日度旅游需求：统一实验方案与执行清单

> 版本：2026-09-23。本文合并《主实验决策与实施 TODO》和《滚动预测、数据划分与时间序列交叉验证》，作为拟公开的方法协议。文中的日期、模型与评价规则是本研究预先固定的设计；引文支持方法原则，不表示已有论文验证了本研究全部具体折次或七个模型在澳门数据上的效果。

## 1. 研究依据与已冻结决策

### CCF-A 会议参考与支持范围

**文献结论的边界：** CCF-A 论文支持滚动起点评估、时间顺序验证、多步预测与非平稳时期分组。它们不会使某一组日期“无可质疑”。可审计的日期清单、防泄漏实现、原始预测、模型版本和稳健性分析，才是回应方法质疑的证据。七个模型的原始发表场所不同；采用滚动预测是本研究共同评价协议，不是声称每篇模型论文都采用完全相同的回测。

### 研究对象、输入输出和任务

澳门有 27 条客源市场日序列，现有文件覆盖 2017-01-01 至 2026-07-31；香港有 2 条入境类别日序列，覆盖 2021-01-01 至 2026-07-31。澳门为主样本，香港为预先定义的外部目的地延伸。香港源数据是入境人次，两地绝对误差不直接相加或比较。

一个预测任务定义为“一个目的地/市场 × 一个预测起点 × 一条未来 28 天完整路径”。统一模型逻辑输入为 `[batch, context_length, 1]`，只有该市场截至起点的访客量；输出为 `[batch, 28]`。各仓库实际 API 可使用其原生张量/数据框，adapter 必须证明语义等价。主实验不使用其他市场、天气、节假日、活动或未来协变量。多变量与协变量单列扩展实验。

主比较包括 13 个现有 baseline：Seasonal Naive、ETS、SARIMA、Ridge、Linear Regression、Random Forest、Gradient Boosting、SVR、Lasso、Elastic Net、Parrot Random Forest 800、LightGBM、本地小型 Transformer；以及 7 个时序模型：**TimesFM 3.0、Chronos-2、Lag-Llama、Moirai、Granite TimeSeries PatchTST-FM、PatchTST、Informer**。

有官方 `q=0.5` 的模型使用中位数作为点预测；只有预测样本的模型使用样本中位数；只有官方点预测时使用该点预测。每步保存 `prediction_raw`、`prediction=max(0,prediction_raw)` 和 `was_clipped`。Seasonal Naive 在 28 天内重复预测起点以前最后一周相应星期的实测值。

### 已知资料与需要核验的条件

- 2020-01-22 作为疫情组起点，依据[澳门政府首宗输入病例公告](https://www.gov.mo/en/news/122165/)；2023-01-08 作为重新开放组起点，依据[澳门政府放宽入境和过境措施公告](https://www.gov.mo/zh-hans/news/664390/)。政策边界只为预先固定折次，疫情对客流的影响可以提前或延后发生。
- 当前 27 条澳门序列合计的日均值：疫情前 98,190.6，2020-01-22 至 2023-01-07 为 15,766.9，2023-01-08 至 2023-12-31 为 78,187.1，2024-01-01 至 2026-07-31 为 105,059.5。这是研究样本合计，**不等同官方全体访澳旅客总量**。
- 对应四阶段的样本天数依次为 1,116、1,082、358、943；日中位数依次为 94,409、17,026、75,514、97,815。此描述性统计用于说明分组理由，最终分析仍以冻结的数据哈希和预先指定的折次为准。
- 对五个预训练模型，须核对权重版本、模型卡与训练语料。若无法排除澳门或香港目标序列与预训练数据重叠，只称“冻结权重、未在本数据上微调”，并披露预训练重叠风险；不能绝对保证严格零样本。
- TimesFM 3.0 权重的非商业许可须记录并遵守；代码许可证与权重许可证分开记录。模型发布时间、预训练结束日期、checkpoint revision 也要写入 manifest。

对每个候选配置，先在澳门 B01–B12、27 个市场上做 `27×12=324` 个 28 天验证任务。每任务计算 MASE，再对市场和折等权平均；主要调参目标为 B 组平均任务级 MASE。候选配置、搜索空间、seed、epoch 决策与最大试验次数都应在外层回测前写入配置并冻结。若最优结果接近，按预先写定的规则选资源需求较低的配置。冻结主配置后，原样在 A01–A13 的 `27×13=351` 个任务上报告疫情压力表现。A、B 两组不得按折数混成一个未声明的总分。若另设跨制度稳健配置，必须预先规定 A/B 权重并用独立 `model_id`。

**香港延伸：** 主超参数由澳门 B 组决定；香港每个外层起点使用自己的全部已知历史拟合，不参与澳门超参数选择。若以后为香港单独调参，应另列一项实验，不能混进“澳门配置外推香港”的结果。

### 外层回测：每次站在当时预测

对任意市场、预测起点 `o`，训练或上下文只能使用 `date ≤ o` 的观测，目标是 `o+1` 至 `o+28`。外层首个起点为 2023-12-31，之后每隔 28 天一个，共 33 个非重叠目标窗口。最后一个规则起点为 2026-06-14，最后一个主窗口目标截止 **2026-07-12**。因此“数据可用到 2026-07-31”与“33 个共同主窗口覆盖到 2026-07-12”是不同概念。可预先加入 2026-07-03 起点作为**单独的终端窗口检查**，覆盖到 2026-07-31；其目标与前一窗口重叠 9 天，故不并入 33 窗口的主排名。

| 起点 | 当时允许使用的历史 | 一次性预测 |
|---|---|---|
| 2023-12-31 | 首日至 2023-12-31 | 2024-01-01—2024-01-28 |
| 2024-01-28 | 首日至 2024-01-28 | 2024-01-29—2024-02-25 |
| 2024-02-25 | 首日至 2024-02-25 | 2024-02-26—2024-03-24 |

第二个起点可以使用第一个目标窗口已经发生的实际观测；第一个任务绝不可用它们。预测期内不输入未来真实值。模型若内部采用自回归生成，只能反馈其**自身的预测值或预测样本**，不能读未来实测值。

主实验使用每个起点以前的**全部可得历史**。PatchTST、Informer 与需要拟合的 baseline 使用全部历史产生训练样本；其单个输入窗口 `L` 仍是有限长度：`X_t=[y_(t-L+1),…,y_t]`、`Y_t=[y_(t+1),…,y_(t+28)]`，训练窗口须满足 `t+28≤o`。最终只把最近 `L` 天送入一次前向运算。零样本模型冻结预训练权重，读取该起点可用历史；超过模型上下文上限时按预先固定的规则截取最近部分。每任务分别记录 `training_history_days`、`lookback_days`、`requested_context_days` 与 `effective_context_days`，不得把“用全部历史生成训练窗口”和“最后一次前向读取全部历史”混为一谈。

PatchTST/Informer 的 epoch 可用 B 组折内的过去验证段选定，例如取折级最佳 epoch 的预定汇总统计量；进入外层后固定 epoch，并在每个起点使用当时全部可用历史重新训练。ETS/SARIMA 和回归 baseline 使用固定规格、在每个起点重新拟合。若为了费用改为每月才重训，必须使用另一 `model_id` 并单独列结果。零样本模型每起点更新上下文而不更新权重。

共同样本主排名规模为 `29 序列×33 起点×20 模型=19,140` 条预测路径、`535,920` 个逐日预测值。180/365 天历史长度单列敏感性分析；全部三种历史设置合计 `57,420` 条路径。每日移动 1 天的完整滚动共有 916 个起点/序列，其目标窗口互相重叠，是另一个运营情景，应单独估计计算量和相关误差的置信区间。

## 3. 评价、记录与复现规则

**主要准确性指标。** 对每个任务先计算 28 天 MASE，星期季节性周期 `s=7`。分母是该任务预测起点以前的历史差值 `mean(|y_t-y_(t-7)|)`；分子是 28 天平均绝对预测误差。若历史分母为零，保存 `undefined_scale` 状态并按预先指定规则排除该任务的 MASE，同时仍报告 MAE 与该情况数量。随后对市场、起点等权汇总，给出均值、中位数、IQR 和最差 10%。不要把不同市场的原始人数误差直接相加作为主排名。

MASE 的分母在外层起点随扩展历史改变，跨越疫情时尤其需要同时报告 MAE、相对 Seasonal Naive 的胜率，并预先指定其他季节基准或固定训练段分母的稳健性分析；不能依据外层排名事后改换主指标。

**辅助指标。** MAE、RMSSE、bias、相对 Seasonal Naive 的胜率；以各起点历史第 90 百分位数预先定义高需求日，报告高需求日 MASE、平均低估量与低估率；分别报告 `h=1,7,14,28` 与整条路径。有预测样本或充分分布时计算 CRPS；仅有分位数时报告 pinball loss/WIS、80% 区间覆盖率与平均宽度。点预测 baseline 仍进入主要准确率比较。数据存在真实零值，MAPE 不作为主要指标。

**时间、资源与费用。** 每次运行分别记录首次下载、缓存后加载、预处理、拟合、预热后推理、后处理、写盘、全部澳门批量总时间；GPU 计时前后同步，记录单任务延迟 p50/p95、批量大小及吞吐量。记录模型权重和镜像大小、峰值进程 RSS、峰值 GPU allocated/reserved/整卡占用、GPU/驱动/CUDA/CPU/RAM。费用统一为每 1,000 个成功 28 天任务，包含训练、推理、API、存储及失败重试；固定云厂商、地区、实例、币种和价格日期。本地 GPU 同时报告实测时间与同口径云实例等价费用。研究者主动工时独立记录，不折算为货币。

**统计推断与覆盖。** 固定共同任务键，只在模型均完成的配对任务上比较损失，并同步报告全体任务覆盖率、失败率和未完成任务。区块 bootstrap 以“市场 × 相邻起点块”保持时序相关；若使用 DM 检验，须处理重叠 28 天路径导致的序列相关。报告效应量和置信区间，避免只靠 p 值决定排名。

**输出与审计。** GitHub 单仓库存放数据管道、统一 adapter、模型容器定义、锁定依赖、配置与测试；每模型独立环境。原始数据、权重、密钥及大型预测结果留在有权限的外部存储。每个 `run_id` 至少保存 `run_manifest.json`、分区 `predictions.parquet`、任务级/聚合指标、`timings.jsonl`、`resources.jsonl`、`costs.parquet`、`failures.jsonl` 和人工 `implementation_log.csv`。Manifest 写明数据 SHA256、任务列表、代码与上游 commit、权重 revision、容器 digest、许可、硬件、seed、batch size、有效上下文、成功/失败/重试数。预测先写临时文件，验证 28 天长度、日期和有限值后再原子重命名，支持断点续跑。

任务索引使用稳定 `task_id`（目的地、市场、起点、历史设置、horizon 的哈希）。每任务还记录 `origin_date`、训练首末日、预测首末日、`fit_strategy`、`hyperparameter_source`、`validation_fold_ids`、`actuals_visible_to_model=false`、预测生成时间与评估时间；结果以 `task_id + model_id + seed` 唯一标识。模型输出可另存 `q_0_1/q_0_5/q_0_9` 与预测样本；无分位数时留空。

**预训练数据审计。** 对 TimesFM、Chronos、Lag-Llama、Moirai、Granite 分别记录模型卡的训练来源、截止日期和可查的重叠清单。模型源码可能不可公开列出全部预训练时间序列；此时报告“预训练交叠未知”。不要把本项目的输入隔离测试等同于能够证明预训练阶段完全无污染。
