# Track 1 实验结果与执行细节

记录日期：2026-10-11。本文按执行顺序整理已经落盘的结果。主路径用隔离计时；敏感性分析和轻量模型的耗时来自当时的并行运行，只用于排序，不替代隔离计时。2026-10-11 补上了零样本模型对齐轻量模型输入后的外层预测。

## 1. 现在能说的性价比

批量、共享一块 RTX A6000、价格日 2026-10-05（GPU 每小时 0.53 美元，CPU 每 vCPU 小时 0.04 美元，后者为未核对的引用价）。研究者工时不计入货币成本。

**全历史、外层 O01–O33（主结果）。** 零样本基础模型是精度最高的一档，每 1000 个任务的成本是几美分。

| 模型 | 澳门 MASE(7) | 每 1000 任务 |
|---|---:|---:|
| 季节性朴素 | 1.883 | ≈0 |
| ETS | 1.639 | 0.019 美元 |
| Chronos-2 | 1.152 | 0.029 美元 |
| TimesFM 3.0 | 1.117 | 0.033 美元 |
| Granite | 1.094 | 0.058 美元 |

从 ETS 换到 Chronos-2，MASE 少 0.49，每 1000 个任务大约多 1 美分。Granite 再准一点，每千任务 6 美分。相对 ETS，Granite 平均每天少错 411 人次，每任务只多 0.000040 美元。已观测到的最小客源市场也盖过这个差价。在这批市场上，不存在“客流要大到某个门槛才值得用大模型”。

PatchTST（每千任务 3.44 美元，MASE 1.590）、Informer（14.78 美元，1.672）和 800 棵树的随机森林（15.56 美元，1.516）又贵又更差。外层最好的原基线 SVR（1.446，每千任务 0.17 美元）仍比 Chronos-2 更贵、更不准。

**历史缩短到 180 天或 365 天之后，优势还在，但缩小了。** 同一历史长度内部比较：180 天时 Granite 1.018、ETS 1.116；365 天时 Granite 0.968、TimesFM 0.969、ETS 1.140。零样本模型仍然领先 ETS，每任务成本仍是不到 0.001 美元。这两个 MASE 不能和全历史的 1.094、1.639 直接相减，因为尺度是在被截短的历史上计算的。

**疫情压力测试 A01–A13 上，大模型的精度优势消失。** 同一组内：TimesFM 0.190，SARIMA 0.196，ETS 0.197，季节性朴素 0.206，Granite 0.208，Chronos-2 0.224。零样本模型没有稳定地好于 ETS 和 SARIMA。这里多花的几美分买不到更低的误差。

**本文提出的轻量模型没有追上零样本模型。** 按 B 组规则选出的冠军 NL01，外层 MASE 1.627，与 ETS 持平，比当时只看本市场历史的 Chronos-2 高 0.475，超出事先写定的 0.05 容差。全局 LightGBM（GL03）外层 1.338，高 0.186。事后的逐市场加日历模型 LL01 外层 1.260，高 0.108。并行运行下，NL01 每千任务约 0.006 美元，GL03 约 0.14 美元。

2026-10-11 把法定日历和其他市场的历史交给能接收它们的零样本模型之后，Chronos-2 变为 1.129，TimesFM 变为 1.077，Moirai 变为 1.562。LL01 仍比对齐后的 Chronos-2 高 0.131。Granite 和 Lag-Llama 的检查点没有这些输入通道，没有改跑。

因此选型可以分成两种情景。平稳的外层、批量出 28 天路径：用 Granite、TimesFM 或 Chronos-2，不要为每个起点重训 PatchTST 或 Informer。疫情冲击窗口：ETS 或 SARIMA 已经够用，零样本模型不是更优的精度工具。不能使用 GPU 时，全历史上外层最好的已冻结基线是 SVR，计算更短的是 ETS。

把 GPU 小时价格换成 0.33 或 1.09 美元，Granite 相对 ETS 的每任务差价仍低于 0.0001 美元。GPU 小时价格除以 CPU 核小时价格要低于 4.26，Granite 的任务成本才会低于 ETS。主口径这个比值是 13.25，所以 Granite 略贵。最小一档客源市场在每人次误差 0.001 美元时，这个比值要高到约 8,400，准确率收益才会被成本吃掉。

体量 V28 是起点前 28 天游客合计。只在 Granite 误差更小的任务上，对数斜率 1.05（区间 0.98–1.21）。0.001 美元下的外推门槛低于样本最小值 104。五档都有正的平均误差下降；最大一档受中国大陆拉动，去掉之后该档其余任务平均少错 488 人次/天，而不是 1,961。27 个市场的中位体量与平均少错的斯皮尔曼相关为 0.98。同一市场内部，体量起伏和误差下降大多对不上。体量与市场类型绑在一起，不能读成景区的五级门槛。

B 组调参没有摊进单次成本：PatchTST 约 3.3 卡时、1.77 美元，Informer 约 18.4 卡时、9.73 美元。这是共享 GPU 的墙钟按并行路数折算的。

LL01 比对齐后的 Chronos-2 高 0.131，比 TimesFM 高 0.183。

## 8. 指标

主指标 MASE(7)：28 天 MAE 除以起点前历史上、周期为 7 的季节性朴素尺度。RMSSE(7) 用同一尺度衡量均方根误差。WAPE 是绝对误差之和除以实际值之和。bias 是误差之和除以实际值之和，负值表示预测偏低。第 1、7、14、28 天的 MASE 用该步绝对误差除以同一个尺度。高需求日是目标日实际值高于起点当时历史的第 90 百分位。

零样本模型另有 80% 区间的覆盖率、宽度和 WIS。WIS 为 `(0.5|y−m| + 0.1×80% 区间得分) / 1.5`。

成本：GPU 模型的每任务实例秒乘以 0.53/3600；CPU 模型的墙钟秒乘以登记线程数，再乘以 0.04/3600。轻量模型在并行运行中的耗时按起点墙钟 × 线程数 / 27 个市场分摊。
