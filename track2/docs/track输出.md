## 1. B 组交叉拟合

对验证起点 \(B_k\)，权重和残差只用 \(B_1,\ldots,B_{k-1}\)。\(k\le 3\) 时用三模型等权，残差系数 \(\lambda=0\)。市场不拆开。主权重在 27 个澳门市场上共享。\(\epsilon=10^{-6}\)。方法之间的差距小于 \(10^{-4}\) 时，保留更简单的一个：等权优先于倒数权重，倒数权重优先于约束最小二乘。

### 1.1 五种点预测

| 编号 | 方法 | B 组交叉拟合 MASE(7) | 是否冻结 |
|---|---|---:|---|
| T2-E0 | 只用 M1 | 0.927 | 否，它是参照 |
| T2-E1 | M1、M2 等权 | 0.934 | 否 |
| T2-E2 | 三个成员等权 | 0.943 | 否 |
| T2-E3 | 验证 MASE 倒数加权 | 0.942 | 否 |
| T2-E4 | 非负且和为 1 的最小二乘 | 0.933 | 是 |

倒数权重是

\[
w_m=\frac{1/(E_m+\epsilon)}{\sum_{j=1}^{3}1/(E_j+\epsilon)},
\]

\(E_m\) 是该成员在训练起点上的市场等权 MASE(7)。约束最小二乘是

\[
\min_{w\ge 0,\;\sum_m w_m=1}\sum_{i,h}\Bigl(y_{i,h}-\sum_{m=1}^{3}w_m\hat y^{(m)}_{i,h}\Bigr)^2.
\]

三个权重的顶点、边和内部驻点可以逐一核对，因此用这个穷举代替在游客数尺度上不稳定的数值优化。二者解的是同一个约束问题。

在 E2、E3、E4 里，E4 的交叉拟合 MASE(7) 最低，比等权低 0.010，超过 \(10^{-4}\) 的并列界，因此冻结 E4。选定之后，用全部 B01–B12 重新拟合一次。这次重拟合的权重是

\[
w_{\mathrm{M1}}=1,\qquad w_{\mathrm{M2}}=0,\qquad w_{\mathrm{M3}}=0.
\]

交叉拟合分数保留，不被这次重拟合覆盖。E4 的交叉拟合分 0.933 高于单模型的 0.927，因为前三个起点按规定使用等权。全量 B 组上的最小二乘则把权重放在 Granite 一个顶点上。

28 组步长权重的交叉拟合 MASE(7) 是 0.943，高于全 horizon 一组权重的 0.933，没有达到再低 0.01 的启用门槛，因此冻结 `per_horizon: false`。

B 组上等权的边际是：Top-1 为 0.927，Top-2 为 0.934，Top-3 为 0.943，加上 Moirai 的 Top-4 为 0.950，七个模型一起是 1.221。第四名及以后不进入外层主集成。

### 1.2 残差与概率

残差用已选定方法的交叉拟合预测：

\[
e_{i,h}=y_{i,h}-\hat y^{\mathrm{ENS}}_{i,h},\qquad
\hat y^{\mathrm{RES}}_{i,h}=\hat y^{\mathrm{ENS}}_{i,h}+\lambda\hat e_{i,h},\qquad 0\le\lambda\le 1.
\]

单步修正不超过未修正预测绝对值的 25%。候选是残差序列上的分步长均值和周期为 7 的季节性朴素，上下文试 28、56、84 天，\(\lambda\) 试 \(0,0.25,0.5,0.75,1\)。\(\lambda=0\) 的交叉拟合 MASE(7) 是 0.933。非零 \(\lambda\) 里最低的是上下文 84 天、\(\lambda=0.25\) 的分步长均值，为 0.934，没有比关闭残差再低 0.01。因此冻结 \(\lambda=0\)，残差模块关闭。外层的 T2-05 与 T2-04 逐位相同。没有启动三个成员的检查点去重跑残差序列。

三个成员的分位数用与点预测相同的冻结权重加权，再按步长排序，保证 \(q_{0.1}\le q_{0.5}\le q_{0.9}\)。因为全量权重是 \((1,0,0)\)，外层区间就是 Granite 自己的区间。B 组交叉拟合上，80% 区间覆盖率是 0.766，平均宽度 1440 人/天，q0.1、q0.5、q0.9 的 pinball 损失是 120、277、188 人/天，80% 区间的 WIS 是 3078。覆盖率离 80% 不到 10 个百分点，没有追加 split conformal。外层 T2-06 的 80% 覆盖率是 0.806，平均宽度 1786 人/天；同一批外层任务上，q0.1、q0.5、q0.9 的 pinball 损失是 119、277、181 人/天，WIS 是 2997。权重是 \((1,0,0)\)，这些区间分数就是 Granite 自己的区间分数。

### 1.3 质量阈值

水平检查只用三个成员的 B 组干净输出。对比的是 28 天预测均值和起点前 28 天实际均值。起点前 28 天均值低于 5 人的任务不进入分位数，合格比值有 888 个。冻结界是这段比值的 0.5% 与 99.5% 分位数：

\[
r\in[0.242,\;1.803].
\]

超时取 Track 1 隔离计时里该成员单起点墙钟的 95% 分位数，再乘 3：Granite 35.7 秒，Chronos-2 18.0 秒，TimesFM 21.2 秒。结构检查要求恰好 28 个有限值、日期连续、起点与历史末日一致。

回退顺序冻结为：三模型冻结集成；一个成员失败则对其余成员按冻结权重重新归一化；这些权重和为 0 时，剩余成员简单平均；三个成员都失败时，用季节性朴素。残差失败只关闭残差，不推翻已经通过检查的集成。当前 \(\lambda=0\)，这一条没有被触发。

冻结文件是 `track2/configs/track2_ensemble_config.yaml`、`track2_fallback_policy.yaml` 和 `track2_freeze_manifest.json`。三份文件记下 SHA256。外层脚本核对过哈希后才套用，没有用外层结果改权重。

### 4.1 可以写进论文的边界

三个成员的 B 组名次是 Granite、Chronos-2、TimesFM。B 组交叉拟合在等权、倒数权重和约束最小二乘之间选了约束最小二乘。用全部 B 组重拟合后，权重是 \((1,0,0)\)。残差没有稳定改进，\(\lambda=0\)。因此外层冻结点预测等于 Granite，MASE(7) 是 1.094。三模型等权是 1.099，自助法区间包含 0。基线前三名的等权是 1.603。

协调器在无故障任务上不改变这个数。10% 故障率下，三模型回退把交付率维持在 1，任务 MASE(7) 是 1.103；无检查的单模型交付率是 0.918。DeepSeek 在 891 个正常任务和 143 个故障任务上都调用了冻结工具，没有改写预测。它的费用档是 D，Granite 点预测的费用档是 B。
